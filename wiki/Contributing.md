# Contributing

See [`js/CONTRIBUTING.md`](https://github.com/bronglil/AnimeCharacters/blob/main/js/CONTRIBUTING.md) in the main repo.

## Rules of thumb

- Keep `LOOK_PRESETS` numbers locked; update tests if you intentionally change them
- Prefer glyph-forward `ascii` look for demos
- Do not morph portrait faces for “anime” — polish only (outline / soft bands)
- Run `cd js && npm test` before opening a PR
