# Gallery

This repository includes a browser gallery of **10 characters × 4 design cards** with colored ASCII previews.

## Run locally

```bash
cd js
npm install
npm run build:characters
npm run gallery
# open http://localhost:5173/gallery/
```

## Characters

Bulbasaur, Charmander, Squirtle, Pikachu, Charizard, Jigglypuff, Meowth, Gengar, Eevee, Mewtwo.

Outputs live under `samples/characters/designs/` and `gallery/`.
