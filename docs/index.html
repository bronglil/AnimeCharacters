anime-ascii

Image → colored ASCII for Node

Readable glyphs with truecolor HTML, ANSI, text, and PNG — built for bots, CLIs, and CI logs.

Get started View source

Install

Scoped package on npmjs. Node.js 18+.

npm install @lilbrong/anime-ascii
npx anime-ascii photo.png --format text,html,png,gif -o out

Also on GitHub Packages as @bronglil/anime-ascii.

Example

Portrait photo with anime-style polish — same face, cel outline, no morph.

API

One call. Pick the formats you need.

import { convertPathColored } from "@lilbrong/anime-ascii";
import "@lilbrong/anime-ascii/ascii.css";

const { text, html, ansi, png, gif } = await convertPathColored("photo.png", {
  look: "ascii",
  style: "anime",
  formats: ["text", "html", "ansi", "png", "gif"],
});

Looks & formats

Locked presets shared by API, CLI, and gallery.

Looks

  • ascii — 56 cols (portrait 64). Readable glyphs for bots and logs.
  • dense — 72 cols (portrait 80). Max detail when readability is secondary.

Formats

  • text — plain glyphs
  • html — truecolor spans + CSS
  • ansi — terminal truecolor
  • png — rendered ASCII picture
  • gif — ASCII picture as GIF (animated 360° when used with depth / --3d)

Why this

Use jp2a for mono C-speed. Use anime-ascii inside JS.

  • First-class Node ESM API and TypeScript types
  • Truecolor HTML + ANSI in one conversion
  • Presets instead of a flag maze
  • ~50ms sprites · ~45–80ms portraits (Node 24)
