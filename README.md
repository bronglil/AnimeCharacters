# anime-ascii

Convert images to ASCII art (Node.js).

```bash
cd js && npm install
npx anime-ascii photo.png -w 72 --style fill -r classic --quality high
```

```js
import { convertPath } from "anime-ascii";

console.log(
  await convertPath("pikachu.png", {
    columns: 72,
    style: "fill",
    ramp: "classic",
    quality: "high",
  }),
);
```
